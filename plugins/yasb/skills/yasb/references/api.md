# YASB QML API

Generated from YASB's docs by `tools/build_references.py`. Read only the file for the type you use.

## Services

Data from Windows and other programs, from `import Yasb`. A widget creates one and reads it.

| QML type | Page | File | What it gives |
| --- | --- | --- | --- |
| `ActiveWindowTracker` | Active window | [service-activewindow.md](api/service-activewindow.md) | The foreground window: its title, app, icon and details, and a text built from your `label`. Updates when the foreground window changes, and when its title changes or it closes or is minimized. |
| `AudioLevels` | Audio visualizer | [service-audiovisualizer.md](api/service-audiovisualizer.md) | The level of each frequency band in the sound an output device plays, from bass to highs, updated many times a second, for drawing a visualizer. It also reports whether sound is playing. |
| `BatteryMonitor` | Battery | [service-battery.md](api/service-battery.md) | Battery charge, charging state and time left, plus rate, voltage, capacity, temperature, cycle count and health where the battery reports them. Updated every `updateInterval`. |
| `BluetoothMonitor` | Bluetooth | [service-bluetooth.md](api/service-bluetooth.md) | Bluetooth radio state, connected devices, known devices and nearby devices, with functions to scan, connect, disconnect and turn the radio on or off. |
| `DisplayBrightness` | Brightness | [service-brightness.md](api/service-brightness.md) | Brightness of your screens and contrast of external monitors, read and set. Laptop screens are controlled through Windows, external monitors through DDC/CI. Screens YASB can't control are not listed. |
| `TimeZones` | Clock | [service-clock.md](api/service-clock.md) | Formats the current date and time for any time zone, in any language. |
| `CpuMonitor` | CPU | [service-cpu.md](api/service-cpu.md) | CPU usage (total and per core), CPU frequency, and core count, updated every `updateInterval`. |
| `DoNotDisturb` | Do not disturb | [service-dnd.md](api/service-dnd.md) | Windows Do not disturb (Focus Assist) status, with functions to change it. Updates when the status changes in Windows, from Settings, the notification center or YASB. |
| `GitHubNotifications` | GitHub | [service-github.md](api/service-github.md) | GitHub notifications (issues, pull requests, discussions, releases and checks), fetched every `updateInterval`, with functions to mark them read and to sign in. |
| `GlazewmWorkspaceList`, `GlazewmTiling`, `GlazewmBindingModes` | GlazeWM | [service-glazewm.md](api/service-glazewm.md) | [GlazeWM](https://github.com/glzr-io/glazewm) workspaces (with window icons), tiling direction and binding modes, with functions to switch them. Connects to GlazeWM's IPC server. While GlazeWM isn't running, YASB retries every 4 seconds and the data is empty. Objects of the same type that use the same server share one connection. |
| `GpuMonitor` | GPU | [service-gpu.md](api/service-gpu.md) | Graphics card usage and memory, plus temperature and fan on NVIDIA and AMD cards, and power draw on NVIDIA cards. Updated every `updateInterval`. Usage is the busiest engine of the card, as in Task Manager. |
| `KomorebiWorkspacesModel` | Komorebi | [service-komorebi.md](api/service-komorebi.md) | [komorebi](https://github.com/LGUG2Z/komorebi) workspaces on the bar's monitor (with layout and window icons), and whether komorebi is paused, with functions to switch workspaces. Updates on komorebi's events. All KomorebiWorkspacesModel objects share one subscription. While komorebi isn't running, `connected` is `false` and `workspaces` is empty. |
| `KeyboardLanguage` | Keyboard language | [service-language.md](api/service-language.md) | Keyboard language and layout of the foreground window, installed layouts, and caps lock, with a function to switch layouts. Updated every `updateInterval`. While a YASB window such as a popup has focus, the previous window's language is kept. |
| `LaunchpadApps`, `LaunchpadLayout` | Launchpad | [service-launchpad.md](api/service-launchpad.md) | Apps from Start's All apps list (without documents, web links, consoles and uninstallers) in your own order, with groups and hidden apps. Functions to start an app, run it as administrator, open its folder and uninstall it. |
| `NowPlaying` | Media | [service-media.md](api/service-media.md) | What's playing in any app that reports to Windows: track, cover, position, with playback controls. Follows the player Windows reports as current. `switchSession()` picks another player until Windows changes its current one. All NowPlaying objects share one connection to Windows' media sessions. |
| `MemoryMonitor` | Memory | [service-memory.md](api/service-memory.md) | RAM in use and free, cached memory, and the page file, updated every `updateInterval`. |
| `AudioInput` | Microphone | [service-microphone.md](api/service-microphone.md) | Default microphone, its level and mute state, and all connected microphones, with functions to change them. Updates when anything changes in Windows. All AudioInput objects share one connection to Windows audio. |
| `NetworkConnections`, `WifiNetworks` | Network | [service-network.md](api/service-network.md) | The internet connection of any kind (Wi-Fi, Ethernet, mobile broadband, or another adapter such as a VPN's), with its signal and whether it reaches the internet. It also covers Wi-Fi: nearby networks, the Wi-Fi switch, and joining, leaving and forgetting networks. |
| `NetworkTrafficMonitor` | Network traffic | [service-networktraffic.md](api/service-networktraffic.md) | Download and upload speed of a network adapter, data moved since the session started, and Windows' usage history by day and hour. Updated every `updateInterval`. |
| `NotificationCenter` | Notifications | [service-notifications.md](api/service-notifications.md) | Notifications in Windows' notification center, their count, and do not disturb, with functions to open, dismiss and clear them. Updates when the notification center changes. All NotificationCenter objects share one listener. |
| `ObsStudio` | OBS | [service-obs.md](api/service-obs.md) | OBS Studio's recording, streaming, virtual camera, studio mode and program scene, with functions to toggle them. Connects to OBS's WebSocket server (obs-websocket 5). While OBS isn't running, YASB retries every 5 seconds and the data is empty. All ObsStudio objects with the same host, port and password share one connection. |
| `PowerSession` | Power menu | [service-powermenu.md](api/service-powermenu.md) | The signed-in user, how long Windows has been running, and functions to lock, sign out, sleep, hibernate, restart and shut down. The user's details are read once and shared by all PowerSession objects. |
| `PowerModes` | Power mode | [service-powermode.md](api/service-powermode.md) | Windows' power mode when plugged in and on battery, with a function to change it. Read when first used and on `refresh()`. Changes made in Windows Settings only show after `refresh()`. |
| `PowerPlans` | Power plan | [service-powerplan.md](api/service-powerplan.md) | Windows' power plans and the active one, with a function to switch plans. Read again when Windows' power plans key in the registry changes. |
| `Process` | Process | [service-process.md](api/service-process.md) | Runs a program or command line and gives what it printed: as text, as JSON, or line by line while it runs. Runs on `run()`, or every `interval` while `active`. Each Process runs its own program and stops it when the Process is destroyed or YASB quits. |
| `QuickLaunchSearch`, `ResultModel` | Quick launch | [service-quicklaunch.md](api/service-quicklaunch.md) | Search across Quick Launch's providers (apps, files, calculator, web search and more), with functions to run what the user picks. All QuickLaunchSearch objects share one search thread and one set of providers, so the `providers` set last applies to all of them. |
| `RecycleBin` | Recycle bin | [service-recyclebin.md](api/service-recyclebin.md) | How many items the Recycle Bin holds and their size, with functions to open and empty it. Updates when the bin changes on a fixed drive, at most every half second. All RecycleBin objects share one watch. |
| `ServerChecks` | Server monitor | [service-servermonitor.md](api/service-servermonitor.md) | Whether your servers and websites answer, how fast, and how long their certificates last, with Windows notifications when they go offline. Checked every `interval` seconds set with `configure()`. All ServerChecks objects with the same settings share one check. |
| `SystrayModel` | System tray | [service-systray.md](api/service-systray.md) | Tray icons of running apps (the icons next to the clock), split in two lists: pinned on the bar, and the rest (usually shown in a popup). The order the user drags them into is saved per screen. All SystrayModel objects read the same tray. |
| `TaskbarApps`, `WindowThumbnail` | Taskbar | [service-taskbar.md](api/service-taskbar.md) | Pinned apps and open windows, grouped by app, with functions to start, switch, close and pin them, and live window thumbnails. Updates when windows open, close or change. All TaskbarApps objects share one window tracker and one set of pins, saved in `%LOCALAPPDATA%\YASB\taskbar_pinned.json`. |
| `WindowsTheme` | Windows theme | [service-theme.md](api/service-theme.md) | Whether Windows is in dark mode, with functions to switch it. Updates when Windows switches, from Settings or from YASB. |
| `AvailableUpdates` | Updates | [service-updates.md](api/service-updates.md) | Updates waiting from Windows Update, winget and Scoop, with functions to install and skip them. Each source is checked on its own interval. Its first check runs 10 to 20 seconds after startup, and nothing shows before it. All AvailableUpdates objects with the same source and interval share one check. |
| `AudioOutput` | Volume | [service-volume.md](api/service-volume.md) | Default output device, its volume and mute state, all output devices, and the apps playing sound, with functions to change them. Updates when the volume or devices change in Windows. `apps` updates on `refreshApps()`. All AudioOutput objects share one connection to Windows audio. |
| `WallpaperLibrary`, `WallpaperThumbnail` | Wallpapers | [service-wallpapers.md](api/service-wallpapers.md) | The images in your wallpaper folders and the one each screen shows, with functions to set a wallpaper, optionally with a transition, and thumbnails of the images. The folders are read on `refresh()`. |
| `WeatherForecast` | Weather | [service-weather.md](api/service-weather.md) | The weather now, by hour and by day, for a place you choose, from Open-Meteo, with a search for places. Fetched every `updateInterval`. The last forecast is cached and shown immediately when YASB starts, if it has the same units and enough days. All WeatherForecast objects with the same `locationId`, `units`, `forecastDays` and `updateInterval` share one fetch. |
| `VirtualDesktops` | Virtual desktops | [service-windowsdesktops.md](api/service-windowsdesktops.md) | Windows' virtual desktops, the one in view and those with windows open, with functions to switch, create, rename and remove them, move and pin windows, and set their wallpapers. Updates when Windows reports a change. All VirtualDesktops objects share one connection to Windows, which reconnects after Explorer restarts. |
| `WindowList`, `WindowThumbnail` | Window switcher | [service-windowswitcher.md](api/service-windowswitcher.md) | Every window that belongs on a taskbar, front to back, with functions to switch to or close one, and live window thumbnails. Updates when windows open, close or change. It reads the same window tracker as [Taskbar](api/service-taskbar.md). |

## Types

Building blocks for widgets, layouts and themes, from `import Yasb`, `import Yasb.Bar`, `import Yasb.Common` or `import Yasb.Themes`, as each file says.

| QML type | Page | File | What it is |
| --- | --- | --- | --- |
| `BackdropPopup` | BackdropPopup | [type-backdroppopup.md](api/type-backdroppopup.md) | A widget popup that opens in its own window. Put the popup's content inside it. When the bar has `backdrop: true`, the area behind `backdropItem` is blurred. |
| `Bar` | Bar | [type-bar.md](api/type-bar.md) | A layout with three slots: `left`, `center` and `right`, or `top`, `center` and `bottom` on a bar at the left or right edge. Each slot shows the widgets listed under its name in config.yaml, in a row along the bar. Widgets in the left slot are aligned to its start, the center slot to its middle, and the right slot to its end. |
| `BarBase` | BarBase | [type-barbase.md](api/type-barbase.md) | The base type for layouts. It gives the bar's surface, theme and right-click menu, but no slots. Add a [WidgetSlot](api/type-widgetslot.md) for each slot you want. [Bar](api/type-bar.md) and [IslandBar](api/type-islandbar.md) are built on it. A layout's root must be one of these three types, or the layout doesn't load. |
| `Environment` | Environment | [type-environment.md](api/type-environment.md) | Reads environment variables, so tokens and passwords can live in YASB's `.env` file instead of in widget files you share. |
| `Hotkey` | Hotkey | [type-hotkey.md](api/type-hotkey.md) | A global keyboard shortcut for your widget. While YASB is running, pressing the keys anywhere in Windows triggers `onActivated`. |
| `IslandBar` | IslandBar | [type-islandbar.md](api/type-islandbar.md) | A [Bar](api/type-bar.md) drawn as a thin rail along the screen edge, with each group of widgets on an island that rises from it. Same three slots as Bar, and everything from [BarBase](api/type-barbase.md) applies. |
| `LoadingLine` | LoadingLine | [type-loadingline.md](api/type-loadingline.md) | A thin loading indicator. While `running`, a bar slides along the line. It usually sits under a popup's header. |
| `Notifier` | Notifier | [type-notifier.md](api/type-notifier.md) | Windows toasts and sounds for widgets. |
| `Theme`, `Colors`, `Bar`, `Popup`, `Menu` | Theme | [type-theme.md](api/type-theme.md) | The colors, fonts and shapes the bar and its widgets share. A theme file's root is Theme, and it sets only what it changes: everything else keeps the default listed here. |
| `WidgetSlot` | WidgetSlot | [type-widgetslot.md](api/type-widgetslot.md) | A container for widgets in a layout. It shows the widgets listed under its `name` in config.yaml, in a row along the bar, or in a column on a bar at the left or right edge. [Bar](api/type-bar.md) has three. In a [BarBase](api/type-barbase.md) layout you add your own. |
